试题展示

第9题 · 智慧农场 MQTT 控制

第9题原题

试题说明

1多维细目表定位

题型/分值单选题 3分
认知层次应用
情境载体百草园智慧农场 MQTT 控制
核心测试点HTTP 通信基本过程；MQTT 发布/订阅机制；API 数据提取
核心素养信息意识、计算思维
能力要求推演
难度★★★
预估得分率0.70

2SOLO 分析

一元结构能识别单一信息，如 rain=0 表示不下雨，或 hum=45 低于 50 表示土壤干燥。
多元结构能同时提取天气数据与湿度数据，知道系统需要依据两个条件进行判断。
关联结构能将“土壤干燥”与“不下雨”建立联系，并结合 MQTT 主题发布机制推断系统会向 school/pump 发布 on 指令。
目标层级：关联结构（Relational）

3命题价值

真实链路将 API 数据提取、条件判断与 MQTT 通信放入同一项目链路。
综合应用考查“数据-算法-通信”的综合推演能力。
以评促学体现素养立意、真实问题与项目化命题导向。

第3题 · 无人机物流最短路径

第3题原题

试题说明

1多维细目表定位

题型/分值单选题 3分
认知层次应用
情境载体无人机物流指令传输
核心测试点路由器主要功能；最短路径算法；网络层 IP 寻址
核心素养计算思维
能力要求推演
难度★★★★
预估得分率0.55

2SOLO 分析

一元结构能识别单一信息，如路由器依据 IP 包头部中的目标 IP 地址转发。
多元结构能分别比较多条路径延迟，如 A→B→D→F、A→C→D→F、A→C→E→F。
关联结构能把网络层寻址与最短路径计算建立联系，推断最佳路径总延迟为 7 毫秒。
目标层级：关联结构（Relational）

3命题价值

真实任务将网络拓扑识别、路径比较与网络层寻址放入同一项目链路。
计算思维考查路径权值比较、最短路径推演与协议定位能力。
素养导向体现“素养立意、真实问题、以评促学”的命题取向。
